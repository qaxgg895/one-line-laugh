A program that writes one funny line — a single sentence of at most 200 characters — to `/output/entry.txt`: *"I set my alarm for 6am to start my new healthy routine, then snoozed it nine times and called that interval training."* The alarm was set for a new healthy routine; the snoozing did the rest.

## Run it

```sh
node main.ts
```
